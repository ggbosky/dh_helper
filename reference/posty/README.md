## Šablona 1: Titulek s přechodem (`titulek`)
Soubory: `titulek-01-jak-sel-cas.webp`, `titulek-02-ms-1947.jpg` (série „Jak šel čas?“: MS 1947, 1985, 1996, 1999, 2000, 2024 …)

- **Červený přechod** zleva shora (tónuje fotku do červena), doprava a dolů slábne.

- Text je stručný, věcný a emotivní: „První *zlato* pro *ČSSR* a obrovská radost *fanoušků*.“
